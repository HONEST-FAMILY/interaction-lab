## 섹션마다
- 모든 섹션: 등장 2개 이상 + 손 반응 1개 이상(올림·누름·끌기·문지르기). 첫 화면만 움직이면 실패.
- 시그니처는 안마다 3~4개: ① 첫 화면 '와'(1초 안에 움직이기 시작, 3초 안에 '만질 수 있다'가 보임) ② 고정 무대 스크롤 장면 1~2개 ③ 손으로 만지는 장면 1개(놓아도 0.5초 이상 여운) ④ 카드 → 상세 공유 요소 전환(520ms, Esc·뒤로 가기로 닫힘).
- 인터랙션은 '내용이 움직이는 것'. 장식 효과(빛 번짐·반짝이·네온·광택·무지개·글리치·흔들림·튕김) 금지.

## 디자인 (어기면 'AI 티')
- 고객 실사진·실제 자료만. 사진 자리에 코드 그림 금지. 사람 얼굴 사진 금지(고객이 준 것 제외).
- 금지: 크림 바탕+세리프 제목+고정폭/대문자 자간 라벨 조합, 1px 액자, 검은 알약 버튼, 외곽선 숫자, 상태 앞 점·네모, 둥근 어두운 카드, 이니셜 동그라미, 숫자 칩, 그라디언트·빛 번짐, 유리, 이모지, '시안/예시/샘플' 글자, 버튼 끝 화살표 남발, 떠 있는 작업용 버튼.
- 촘촘하게: 큰 빈칸·거대 글자만 있는 구간·작은 회색 본문만 있는 구간 금지. 본문 폭 1320(여백 PC 60·폰 20). 섹션 제목 PC 48~64px·폰 28~34px, 본문 16~18px(폰 15~16), 한글 word-break: keep-all.
- 사진: 한 사이트 안 색 보정 통일. 600px 이하 사진은 2배 넘게 키우지 않는다.
- 폰: PC 디자인 다음에 폰을 따로 다듬는다. 화면 아래 고정 앱바(탭 4개, 높이 60+안전영역, 현재 위치 표시, PC에선 숨김, 본문 아래 여백), 누르는 곳 44px 이상, 가로 넘김 영역은 touch-action: pan-y.
- 넓은 화면 1920·2560에서 첫 화면 글 칸이 좁아지거나 사진이 깨지지 않게.

## 기술
- 정적 파일, 상대경로, 바닐라 JS(모듈 가능). 외부는 글꼴 CSS만. WebGL 가능(실패하면 사진·정지 화면).
- rAF 루프 하나, 화면 밖·숨긴 탭이면 멈춤, DPR 상한 2, transform·opacity 위주.
- 콘솔 오류 0, 우리 파일 404 0(favicon은 data:). 새 코드에 주석 0.
- JS·WebGL 전에도 그림이 이미지로 먼저 보인다. 가림막은 스크립트가 돌 때만, 2.6초 안에 준비 안 되면 걷힘.
- 자산 경로는 문자열 그대로 적는다(발행 도구가 적힌 파일만 골라 담는다).
- 원본은 수정하지 않는다. 작업은 {작업 폴더}/<안>/ 안에서만. 발행(커밋·푸시)은 메인이 한다.

## 검수 (작업자가 끝까지 스스로) — 도구는 interaction-lab 저장소 tools/web
- 미리보기: http://127.0.0.1:{포트}/<안>/index.html (메인이 serve.py로 띄워 둠, 새로 띄우지 말 것).
- 크롬 확장은 메인 전용. 작업자는 헤드리스 크롬(python playwright, channel chrome, --enable-gpu --use-angle=d3d11 --ignore-gpu-blocklist), 한 번에 하나씩.
- 전체 캡처 fullshot.py + sheet.py, 움직임 rec.py(시간 라벨 시트), 폭 9개 widths.py(390·412·768·980·1024·1280·1440·1920·2560): 가로 넘침 0, 글자 가림 0, 콘솔 오류 0. 폰은 터치로.
- 동작 줄이기에서도 내용 전부 보임, 빠르게 끝까지 내렸을 때 숨은 요소 0.
- 캡처는 {qa 폴더}/<안>/ 에. 끝나면 짧게 보고: 섹션별 움직임(아래 12종 번호), 잰 값, 남은 문제.

## 1안에서 잡은 실패 — 처음부터 피할 것
1. 첫 화면 자동 시연이 화면 일부만 바뀌면 '얼룩·오류'로 읽힌다 → 화면 전체가 확실히 바뀌는 시연.
2. 구간 전환에서 앞 구간 글까지 회색으로 덮지 않는다 → 다음 구간이 '열리는' 방식.
3. 폰 첫 화면 그림이 아래에 작게 붙고 위가 빔 → 세로 화면 전용 크롭(그림 약 70%, 제목 위 20% 안, 높이 100svh−앱바).
4. 폰 고정 무대 아래 UI가 앱바 밑에 깔림 → 앱바 높이+안전영역+12px 위로.
5. 투명해진 겹친 레이어가 글자를 가림 → pointer-events: none, 투명이면 visibility: hidden.
6. 안내 문구가 장식 그림 밑에 깔림 → 겹치지 않는 자리.
7. 큰 흰 동그라미 버튼, 화면 폭 원색 띠 → 사각 버튼, 원색은 버튼에만.
8. 사진 위 큰 글자 → 사진 아래 18% 안 + 사진 아래쪽만 살짝 어둡게(그림자 금지).
9. 효과 경계선이 네온처럼 빛남 → 색을 눌러 숯불 테두리처럼.
10. 숫자가 줄바꿈으로 갈라짐 → 한 덩어리('2003.10.1', '480만+').
11. 사진 없는 자리를 원색 면·큰 글자로 때움 → 같은 높이의 글 카드.
12. 선 그림이 굵은 사인펜 낙서처럼 보임 → 심 2px + 둘레 번짐 + 짧은 조각 제거.
13. 장면 사진이 화면의 1/4 → 화면 폭 약 60%·높이 약 62vh.
14. 김·연기가 사진 전체를 덮는 막 → 가는 가닥, 사진의 70% 이상은 늘 선명.
15. 손 조작 무대가 작음 → 섹션 폭 대부분, 조각 160~220px.
16. 도형 변신이 무엇인지 안 읽힘 → 알아볼 표지(필름 구멍·손가락 다섯).
17. 3D 사물이 비틀린 긴 띠 → 기울기 약하게, 두께·속면을 보여 실물처럼.
